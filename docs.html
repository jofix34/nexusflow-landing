Guía de Inicio Rápido

Despliega NexusFlow en 60 segundos

El motor de NexusFlow Titanium Edition se distribuye como una imagen oficial lista para producción.

1. Ejecutar con Docker

Abre tu terminal (PowerShell en Windows o Bash en Linux/Mac) y ejecuta:

# Crea volumen local y arranca el contenedor
docker run -d --name nexusflow \
  -p 5678:5678 \
  -e GENERIC_TIMEZONE=Europe/Madrid \
  -v ~/.nexusflow:/root/.nexusflow \
  nexusflow/silver-edition:latest

2. Docker Compose (Con PostgreSQL y Redis)

Para entornos de producción con alta carga de eventos y almacenamiento persistente: 

version: '3.8'

services:
  nexusflow:
    image: nexusflow/silver-edition:latest
    restart: always
    ports:
      - "5678:5678"
    environment:
      - DB_TYPE=postgresdb
      - DB_POSTGRESDB_HOST=postgres
      - DB_POSTGRESDB_DATABASE=nexusflow
      - DB_POSTGRESDB_USER=nexus
      - DB_POSTGRESDB_PASSWORD=secret_titanium_key
    depends_on:
      - postgres
      - redis
